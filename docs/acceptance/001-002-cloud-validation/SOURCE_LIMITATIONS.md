# 证据来源与限制

## 证据来源

- 腾讯云 DMC 真实执行结果，由用户在验收过程中粘贴或截图提供。
- 腾讯云 SQL 变更工单/执行页面截图。
- 当前仓库内经静态审核通过的 001/002 SQL 文件。
- 2026-08-20 广州数据库只读盘点结果。

## 已知限制

1. 当前会话可访问的临时截图中，未发现覆盖 001 全部 18 项结果的原始截图。因此 001 以对话中保留的完整文字结果为主证据，并明确记录该限制，不伪造或补写截图。
2. `sql-snapshots/` 是 2026-08-20 归档时的仓库版本。除非文件另有部署哈希证明，否则不能把它表述为当时 DMC 实际执行文件的逐字节副本。
3. 双会话验证的 DMC 页面截图只覆盖会话 A 的锁定状态和用户上下文；会话 B 的 PID、开始/返回时间、合并结果以及最终清理结果来自当时保留的原始文字输出。
4. 数据库内验收测试行已完成清理；`CLEANUP_PASS,0,0,0` 和 2026-08-20 的 13 表全空盘点共同说明当前库内不再保留这些测试行。验收证据必须依赖本档案，而不能依赖数据库行长期存在。
5. 截图可能包含控制台资源标识、数据库名和测试用户 ID，但本档案不保存数据库密码、SecretId、SecretKey、Token 或其他认证秘密。
