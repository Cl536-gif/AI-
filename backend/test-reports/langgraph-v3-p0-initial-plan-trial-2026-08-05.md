## 失败与幂等测试

### 资料门禁

- 生理男性：不能生成长期方案命令。
- 身体资料不完整：不能生成长期方案命令。
- 经期资料不完整：不能生成长期方案命令。
- 活动量不能标准化：不能计算，不能启动试用。

### 计算失败

注入不支持的年龄后：

- 能量计算抛错。
- 不创建计划。
- 不启动试用。

### 正式交付失败

模拟正式交付第一次失败：

- 服务保持 `profile_confirmed`。
- 体验不启动。
- 计算记录和方案草稿保留用于安全重试。
- 第二次重试复用原计算和原草稿，不重复创建。
- 重试成功后才原子切换为活动方案和 `trial_active`。

### 重复请求

正式交付后再次提交同一命令：

- 不新增能量计算。
- 不新增方案版本。
- 不改变正式方案ID。
- 不重置试用开始时间。

### 第13天续费提醒

- 第13天之前不创建提醒。
- 到点只创建一条待发送提醒。
- 重复调度不会重复创建。
- 发送成功后不会再次进入发送队列。
- 已过期用户不会新建续费提醒。

## 测试中发现并修复的问题

身体数据抽取器会把“久坐”标准化成 `sedentary`，而计算准备器原本只认识中文“久坐”和 `light`，导致真实流程最后一步被安全门禁拦截。现已统一映射：

- `sedentary` / `low_active` / 久坐 → `light`
- `moderately_active` / 中等活动 → `moderate`
- `very_active` / 高活动 → `heavy`

该问题已加入自动回归测试，不能通过默认值绕过。
