# LangGraph V3 P0：用户问题优先回答回归

- 日期：2026-08-05
- 范围：明确问题识别、先回答再恢复资料收集、同句信息保留、重复回答拦截
- 结论：核心路由通过；发现一项已进入 V3 统一评审清单的旧确认话术问题，未伪报为零问题

## 实现防线

1. 高置信问句由确定性规则直接识别，模型无权否决“我现在该怎么吃”等明确求助。
2. 模糊问句才交给低温分类模型判断。
3. 专用回答节点先回答问题，原始用户消息继续交给后续状态节点解析。
4. `directQuestionAnsweredThisTurn` 阻止旧有的顺带回答逻辑重复回答同一问题。
5. 回答质检最多重试两次，检查：不夹带资料收集问题、回应外卖/运动/手表条件、食物单位不混用。

## 自动化回归

执行：

```text
node manual-test-direct-question-priority.js
node manual-test-returning-user-context.js
node manual-test-initial-long-term-lifecycle.js
node manual-test-long-term-sex-eligibility.js
```

结果：全部通过。

覆盖：

- “我今天怎么吃”无需依赖分类模型即可进入回答分支。
- 同一句“22岁，这是什么意思”先回答，再回到身体资料解析。
- 已有档案的新会话回答后直接结束，不会由回访节点重复回答。
- 新用户问完产品问题后仍会继续首次资料收集。
- 首个长期方案、14天体验、生理性别资格规则无回归。

## 真实接口测试一：已有档案用户复杂提问

用户：

```text
我回来啦，这几天课太多，有两天没按计划吃，还偷吃了薯片。今天中午只能点外卖，晚上会跑步40分钟，手表一般显示消耗三百多千卡。我现在该怎么吃？
```

秘书先发送情绪支持，随后给出当餐外卖搭配，并明确说明：晚间跑步可正常安排，手表三百多千卡只作为参考，不做等量补偿。没有重新自我介绍，没有重启六项资料收集，没有在结尾追问预算。

接口状态：

```text
contextAccessMode=basic_profile_only
profilePersistence=unchanged
```

## 真实接口测试二：同一句回答资料并询问功能

用户：

```text
食堂，你能提醒我每天吃什么吗？
```

秘书：

```text
可以，如果你选择长期规划服务，我会按照你设定的频率和时间提醒，并结合记录做阶段性调整；免费的科学饮食问答不会主动推送提醒。

我确认一下，你目前的身材目标是“减脂”，对吗？
```

核验：

- 提醒功能只回答一次，不再额外生成一份无关餐单。
- 当前待确认的“减脂目标”仍按原顺序继续。
- “食堂”进入后续待确认队列；用户确认目标后，系统继续询问食堂场景，没有丢失该信息。

## 未纳入本 P0 的已知话术项

后续确认“食堂”时，旧确认生成节点仍出现：

```text
诶，你刚才是说在食堂吃饭吗？我怕听岔了，想跟你确认下～
```

这违反已经确认的 V3 话术规则（禁用“诶、你刚说、你刚才”），属于统一话术评审清单中的存量问题。本 P0 只解决问题优先级与状态恢复；统一话术改造时必须用确定性模板/质检一并清除，并加入固定回归断言。
