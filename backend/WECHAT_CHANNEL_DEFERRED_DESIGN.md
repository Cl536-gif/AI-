# 企业微信渠道待实施设计记录

> 状态：文案与方向已确认，暂缓实现；不影响001—003批次。

## 身份边界

- 企业微信用户从第一条消息起即为确定身份，不创建匿名游客身份。
- 不调用002游客身份合并机制。
- 未来小程序、手机应用与企业微信之间的身份关联另行设计，不自动套用游客合并。

## 首次开场

开场只提供“免费问答”和“长期方案”两种选择，不展示额外身份分类。话术必须由确定性模板发送，不经过模型改写。

确定文案：

> 宝子你好呀，我是你的饮食秘书。现在先在企业微信陪你，后面也会开通小程序和手机应用。
>
> 免费问答可以随时来找我，但我不会主动推送，也不会持续调整方案。如果你想让我按约定时间跟进，并根据每个阶段的记录调整方案，可以进入长期方案，前14天免费试用，之后每14天收费19.9元。
>
> 直接告诉我“免费问答”或“长期方案”就好。

无法识别选择时：

> 刚才没听清楚。你直接告诉我“免费问答”或“长期方案”就好。

选择长期方案后：

> 好，那我们开始建档。我会一项一项问，不用一次全说完。

首次开场需要按用户与渠道持久化版本和发送时间，不能根据是否已有档案推测。

## 注销意图

明确提出注销账号、删除账号或删除资料时：

> 知道了，我已经把你的注销申请记下来了，会尽快安排处理。现在是登记成功，账号和资料还没有正式删除，处理完成后我会再告诉你。

只表达“不想用了”“先不用了”等含义不明确时：

> 我记下你不想继续用了。为了不误删账号和资料，我会先把这条记为待确认，处理前再跟你确认一次。

只有后台成功记录后才能回复“已经记下”。后台记录结构沿用已审核方向：专用注销请求表、结构化事件类型、幂等消息键、可查询状态，不保存用户原话；本阶段不实现自动删除。

## 主动触达共同额度

任何因“3个月无对话自动降级”产生的主动消息，都必须计入同一个“每周最多一次主动触达”额度，不能另算，也不能补发积压消息。

## 定价事实来源

- 长期方案最终定价为19.9元/14天，不按月计费。
- 价格、试用天数和计费周期的唯一运行时配置保存在 `src/pricingConfig.json`，不得在提示词或业务节点中另写一份价格常量。
- 本文保留经审核的渠道展示文案；未来实现时仍从配置生成或校验其中的客观定价事实，避免配置与话术漂移。

## 2026-08-28 企业微信真实联调入口决策

当前企业微信账号为未认证的内部测试账号，CloudBase Run 默认域名因主体属于第三方服务商，不能直接用于企业微信回调验证。

### 决策状态

**已否决临时公网 IP 反向代理方案。企业微信真实联调暂停，等待备案通过后直接使用企业主体 HTTPS 域名。**

否决依据：

- 项目现有轻量应用服务器 `diet-secretary-icp-sh` 位于中国内地，当前正作为 ICP 备案云资源，不能在备案审核期间提前承载公网回调服务。
- 腾讯云 ICP 备案规则明确：托管于中国内地服务器、仅能通过互联网 IP 地址访问并提供非经营性互联网信息服务的场景同样需要依法备案。
- 首次备案或新增网站在取得备案号之前，不允许通过公网域名或公网 IP 对外访问；提前开放可能导致管局核验失败、备案被驳回或被要求关闭服务。
- “仅提供 API、无面向用户网页时可暂不办理公安联网备案”属于 ICP 备案完成后的公安联网备案规则，不能作为 ICP 备案审核期间开放公网 API 的豁免依据。
- 企业微信客服关于未认证企业可尝试 IP 形式回调的建议，只说明企业微信可能接受 IP 格式，不改变中国内地服务器在 ICP 备案审核期间不得对外提供服务的要求。

官方参考：

- 腾讯云《备案场景》“IP 访问的网站 ICP 备案”：<https://cloud.tencent.com/document/product/243/18910>
- 腾讯云《备案期间》：<https://cloud.tencent.com/document/faq/243/19637>
- 腾讯云《备案审核》“审核期间不能通过公网域名/IP访问”：<https://cloud.tencent.com/document/faq/243/19650>

暂停期间约束：

- 不在 `diet-secretary-icp-sh` 开放 TCP 8000 或其他新增公网入站端口。
- 不在该服务器安装或启动 Nginx、Caddy 等临时反向代理。
- 不搭建临时中国香港或境外转发服务器。
- `WECOM_CHANNEL_ENABLED` 的真实联调保持暂停，不进行 URL 验证、真实消息回调或主动推送验证。
- 继续保持 `USER_STORE_ADAPTER=sqlite`，不执行 PostgreSQL 全量切换。

恢复条件与执行顺序：

1. 等待企业主体域名备案/申报结果通过，并确认域名可依法对外提供 HTTPS 服务。
2. 将企业微信回调地址配置为企业主体自有域名下的 HTTPS `/api/wechat-callback`。
3. 继续限制在 `WECOM_TEST_ALLOWLIST` 内的内部测试成员，不因启用真实联调而自动视为正式对外上线。
4. 依次完成企业微信 URL 验证、真实消息回调和主动推送验证，并将完整原始输出保存为 Markdown 测试报告。
