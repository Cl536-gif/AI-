## 已验证能力

1. 缺少独立确认、实例/池复核值不一致、容量预算超限或回滚阈值缺失时均在联网前失败关闭。
2. 应用连接上限按最大实例数乘每实例池上限计算，且不得超过应用预算；应用预算加运维预留不得超过数据库连接上限。
3. DMS脚本只读获取数据库容量及聚合连接计数，不读取连接地址、SQL正文、身份或凭据。
4. 独立临时服务使用两个实例、每实例池上限1；实际数据库readiness通过且池等待为0。
5. 健康实值产生`continue`，人工构造的饱和/等待快照产生`rollback`。
6. 正式UserStore继续使用SQLite，full能力门禁继续返回未就绪。

## 发布边界

- 本验收证明容量预算和回滚信号计算可在真实私网数据库环境工作。
- `rollback`目前是供发布控制面消费的固定安全信号；应用尚未自动调用CloudBase回滚接口。
- 本验收不授权全量PostgreSQL切换，不代表生产观察窗口、数据迁移、稳定回滚制品或备份恢复已经完成。
- 容量预算基于本轮固定双实例、池上限1的拓扑；实例或池配置变化必须重新评审。
- 验收档案不保存域名、地址、账号、密码、连接串、Pod名称或真实用户数据。
