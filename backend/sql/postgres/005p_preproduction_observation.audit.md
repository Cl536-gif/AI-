# 005p 独立预生产观察窗口

## 目标

在独立CloudBase临时服务中使用与最终方案相同的双实例PostgreSQL UserStore、共享PostgreSQL checkpointer和受保护HTTP入口，持续不少于60分钟并完成不少于100个无用户数据的真实请求。

## 通过条件

- 观察时长至少60分钟，成功请求至少100。
- 必须观测到两个不同实例指纹。
- readiness失败、连接超时、事务失败、身份失败、副作用失败、HTTP 5xx和连接池等待最大值均为0。
- 所有请求使用固定测试身份和不依赖档案的通用问题；证据不输出回复正文、用户ID、内部thread键或凭据。

## 运行边界

- 临时服务：`diet-secretary-preproduction-005p`，最小/最大实例均为2，始终持续运行。
- 公网地址必须是CloudBase HTTPS默认域名，观察请求通过负载均衡入口而非本机回环。
- 正式服务和正式流量不在本阶段改动；通过也不自动执行生产切换。
- 观察后先精确清理checkpointer，再在DMS按固定身份清理UserStore，最后删除临时服务。
